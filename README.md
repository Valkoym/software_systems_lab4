# Automated Library System
[![Python CI Application](https://github.com/Valkoym/software_systems_lab4/actions/workflows/python-app.yml/badge.svg)](https://github.com/Valkoym/software_systems_lab4/actions/workflows/python-app.yml)
## Description

Automated Library System is a software system for managing library operations, books, readers, reservations and reports.

## Functionality

- Book management
- Reader management
- Book reservations
- Loan tracking
- Penalty management
- Report generation
- CI/CD pipeline with GitHub Actions
- Automatic testing with unittest
- Code style validation using flake8

## Technologies

- Python
- GitHub Actions
- flake8
- unittest
- Markdown

## Run Tests

```bash
python -m unittest test_calculator.py
```
